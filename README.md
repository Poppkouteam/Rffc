# Geometry Rush

Ритм-платформер для Android в стиле Geometry Dash. Кубик сам бежит вперёд под
музыку — нажимай на экран, чтобы прыгать, и не врезайся в шипы и стены.

## Как установить

Готовый APK лежит в [`apk/GeometryRush.apk`](apk/GeometryRush.apk). Скачай его на
телефон и открой (нужно разрешить установку из неизвестных источников).
Требуется Android 7.0+.

Также APK собирается автоматически в GitHub Actions (вкладка **Actions** →
последний запуск → артефакт `GeometryRush-apk`).

## Управление

- **Тап / удержание** — прыжок (удержание прыгает сразу при приземлении).
- **Тап на жёлтом орбе** — прыжок в воздухе.
- **Режим корабля** (после розового портала): держи палец — корабль летит вверх,
  отпусти — вниз. Зелёный портал возвращает кубик.
- Жёлтый **батут** на земле подбрасывает высоко вверх сам.
- Кнопка паузы — в правом верхнем углу, «Назад» тоже ставит паузу.

## Что есть

- 3 уровня: «Первый ритм» ★, «Небесный полёт» ★★, «Неоновая ярость» ★★★
- Процедурная электронная музыка для каждого уровня (синтезируется на лету)
- Шипы, блоки-платформы, орбы, батуты, порталы корабля, финиш
- Счётчик попыток, прогресс-бар, рекорд по каждому уровню сохраняется
- Частицы, взрыв при смерти, пульсация под бит, смена цвета по ходу уровня

## Сборка из исходников

```
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`. Нужны JDK 17+ и Android SDK
(platform 34).

## Свои уровни

Уровни описаны текстом в
[`Levels.java`](app/src/main/java/com/rffc/geodash/game/Levels.java):
каждая строка — ряд клеток (верхний ряд первым, последний стоит на земле).

| Символ | Объект |
|---|---|
| `#` | блок |
| `^` | шип |
| `v` | шип на потолке |
| `o` | жёлтый орб |
| `_` | батут |
| `S` | портал корабля |
| `C` | портал кубика |
| `.` | пусто |

Физика (`World.java`) не зависит от Android, поэтому проходимость уровней можно
проверять ботом на обычной JVM.
